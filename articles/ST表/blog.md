## ST表

ST表是一种利用倍增思想做离线 RMQ 问题的数据结构。

时间复杂度：$O(n\log n)$ 预处理， $O(1)$ 查询。

### 预处理

现在我们有一个长度为 $n$ 的数组 $arr$，我们想要查询区间内的最大值。

设 $S(i,j)$ 为下标 $i$ 为左端点，长度为 $2^j$ 的区间内的最大值。

考虑区间 dp：区间 $[i,i+2^j-1]$ 可以分割成 $[i,i+2^{j-1}-1]\ ,\ [i+2^{j-1},i+2^j-1]$，两个子区间。

即状态转移方程：$S(i,j)=\max\{S(i,j-1),S(i+2^{j-1},j-1)\}$。

### 查询

现在我们要查询区间 $[l,r]$ 内的最大值。

一般来说有两种做法：

#### 方式 1

我们将查询的区间的长度二进制分解，然后倍增查询。

例如我们要查询 $[7,11]$ ，区间长度为 $5$ ，二进制为 $101$，那么我们就可以将区间划分为 $[7,10],{11}$。即我们在 ST 表中分别查询 $S(7,2),S(11,0)$。

这种方式的特点在于最终在 ST 表中查询的区间互不重合。

#### 方式 2

我们直接找到一个 $k=\lfloor\log_2{(r-l+1)}\rfloor$，然后查询 $S(l,k)\ ,\ S(r-2^k+1,k)$。

这种方式特点也很明显，预处理一下 $log_2x$ 即得到 $O(1)$ 的查询复杂度。

预处理 $log_2x$ 的一种实现：

```
int lg[2000010];//预处理log(i)+1
void refer()
{
	for(int i=1;i<=n;i++)
	{
		lg[i]=lg[i-1]+(1<<lg[i-1]==i);
	}
}
```
