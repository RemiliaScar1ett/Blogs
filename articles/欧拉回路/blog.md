## 欧拉回路

### 定义

- **欧拉路径**：如果图 $G$ 中有一路径经过且仅经过每条边一次，则称这条路径为欧拉路径。

- **欧拉回路**：如果图 $G$ 中有一回路经过且仅经过每条边一次，则称这条回路为欧拉回路。

定义非常的简明，与欧拉回路有关的问题不少都与一笔画有密切联系。

### 性质

根据定义我们知道，对于在路径上的点，只要能进入这个点，就一定能出去。

定义无向图中度数为奇数的点为奇点，度数为偶数的点为偶点。一个图中除了奇点就是偶点。

则我们可以得出如下结论：

- 一个无向图存在欧拉回路，当且仅当这个图所有的顶点都是偶点，且该图有且只有一个边集不为空的子图。

- 一个无向图存在欧拉路径，当且仅当这个图的奇点数量为 $0\ or\ 2$ ，且该图有且只有一个边集不为空的子图。

- 一个有向图存在欧拉回路，当且仅当这个图中所有点的入度等于出度。

- 一个混合图(即同时存在有向边和无向边的图)存在欧拉路径，当且仅当存在一个对所有无向边
定向的方案，使得所有点的入度等于出度。

### 求法

对于性质中提到的前三种情况，我们可以用DFS来求。

首先使用一个标记数组去重，然后对于每个点遍历所有出边。DFS的答案在搜索完成回溯时倒着记录

若直接记录的话，在遇到割点的时候可能会导致无法记录答案的问题。

代码大概长下面这个样子

```cpp
int dfs(int x)
{
    for(int &i=head[x];i;)
}
```
