## KMP字符串匹配

### 简介

这真的是个很聪明的算法。

对于字符串匹配，我们一般都会想到如下代码
```cpp
int main()
{
	string s1,s2;
	cin>>s1>>s2;
	for(int i=0;i<s1.length;i++)
	for(int j=0;j<s2.length;j++)
	{
		if(s1[i+j]!=s2[j]) break;
		if(j==s2.length-1) printf("%d ",i);  
	}
}
\\随手写的，不保证正确性（（（s
```

~~其实这个暴力一般够用了。~~

但是 $D.E.Knuth$ ，$J.H.Morris$ 和 $V.R.Pratt$ 三人对其进行了改进，得到了KMP算法。KMP的核心思想是**利用匹配失败(以下简称“失配”)后的信息**，尽量减少**模式串**(要找的串)**与主串**(要在里面找的串)**的匹配次数**。通过预处理一个 $next$ 数组实现，理论时间复杂度 $O(m+n)$  

---

### 主串匹配

观察暴力，其实我们发现我们每次匹配完毕，无论失败还是成功，都是直接回到了起点，这显然是不必要的。

进一步观察我们发现：当匹配过程在第 $i$ 位失配（即前 $i-1$ 位相同，第 $i$ 位不同）时，我们可以不重新匹配，而是将主串中已经被比较过的子串的一个后缀，和模式串的前缀尽量对齐。

比如在 `abcabcdhijk` 中查找 `abcabb`：
现在假设我们做了如下比较：
```
abcabcdhijk
abcabb
```

此时在模式串 $j=5$ 处失配，我们考虑主串已比较部分的后缀，与模式串的前缀最大化对齐（主串“|”之前是已比较部分）：

```
abcabc|dhijk
   abcabb
```
至此，我们只需要比对后面的 "abb" 是否相同，而不用再比较前面的 "abc"。同时，主串的指针 $i$ 也不会回退。

继续考虑，我们发现由于 $j$ 之前的部分（不包括 $j$）和主串是匹配的，所以我们实际上找的是：模式串 $j$ 之前（不包括 $j$ ）的这一段子串的后缀，和模式串的前缀的最大匹配长度。

主串匹配代码：

```cpp
for(int i=1,j=0; i<=m; i++)
{
	while(j&&s[i]!=p[j+1])	j=next[j];//失配，则 j 回退一次
	if(s[i]==p[j+1]) j++;
	if(j==n)						   //匹配成功
	{
		cout<<i-n<<" ";
		j=next[j];
	}
}
```

其中 `next[i]` 表示模式串以 $i$ 位结尾（包括 $i$）的子串中，前缀和后缀的最大重合长度。

这个信息只和模式串自己有关，我们可以预处理 `next` 数组。


### next 数组

暴力求 `next` 数组仍然是 $O(n^2)$ 的（假设模式串和主串长度同阶）。要想降低复杂度，我们需要更快速的 `next` 求法。

首先指定特殊值：`next[1]` 为 $0$ (这里的前缀/后缀不能是整个模式串)，我们从 $i\ge 2$ 开始考虑。

对于第 $i$ 位，我们可以观察到：当模式串第 $1\sim j$ 位已经和 $i-j\sim i-1$ 匹配成功，但在 $j+1$ 和 $i$ 处失配时，我们移动模式串的过程和主串匹配时完全一样。因此我们仍然可以沿用主串匹配时候的思路：利用已经求出的 `next` 来求。

```cpp
for(int i=2,j=0; i<=n; i++)
{
	while(j&&p[i]!=p[j+1]) j=next[j];
	if(p[i]==p[j+1]) j++;
	next[i]=j;
}
```

显然，这里的 $j$ 一定小于 $i$，`next[j]` 一定是已知的。

### 完整代码

```cpp
#include<bits/stdc++.h>
using namespace std;

const int N=1e6+10;

int n,m;
char p[N],s[N];
int next_[N];

int main()
{
	cin>>n>>p+1>>m>>s+1;

	for(int i=2,j=0; i<=n; i++)
	{
		while(j&&p[i]!=p[j+1]) j=next_[j];
		if(p[i]==p[j+1]) j++;
		next_[i]=j; //next数组含义：以i为终点的后缀和前缀相等的最长长度
	}

	/*匹配过程*/
	for(int i=1,j=0; i<=m; i++)
	{
		while(j&&s[i]!=p[j+1])	j=next_[j];
		if(s[i]==p[j+1]) j++;
		if(j==n)
		{
			cout<<i-n<<" ";//注意：此时的i在匹配的终点
			j=next_[j];
		}
	}
	return 0;

}

```
